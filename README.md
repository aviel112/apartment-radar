# Apartment Radar

מעקב דירות במרכז הארץ — מיון לפי מחיר למ״ר, ציון כדאיות ופוטנציאל התחדשות עירונית.

מתעדכן אוטומטית פעמיים ביום (09:30 / 19:30) ע"י המשימה `daily-apartment-search-center`.

- `index.html` — הדשבורד
- `data.js` — המאגר (זה מה שמתעדכן בכל ריצה)

מקורות: יד2 · מדלן · פייסבוק מרקטפלייס
